# Orfeo ed Euridice nel Novecento

App interattiva sulle riscritture novecentesche del mito di Orfeo ed Euridice: testi di Rilke, Cvetaeva, Bufalino e Miłosz, con analisi, confronto e quiz finale di 20 domande sulla comprensione dei testi.

## Contenuto

- `index.html`: l'intera app, in un unico file senza dipendenze (solo i font di Google Fonts).
- `.nojekyll`: dice a GitHub Pages di servire il file così com'è.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub (ad esempio `orfeo-euridice`).
2. Carica `index.html`, `README.md` e `.nojekyll` nella radice del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment** scegli **Deploy from a branch**, seleziona il branch `main` e la cartella `/ (root)`, poi **Save**.
5. Dopo uno o due minuti l'app sarà online all'indirizzo `https://<tuo-utente>.github.io/orfeo-euridice/`.

## Uso didattico

Le schede seguono l'ordine cronologico dei testi: Rilke (1904), Cvetaeva (1923), Bufalino (1986), Miłosz (2002). Rilke e Miłosz sono riportati in estratto, come nel documento di partenza.
